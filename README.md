# 🧪 QA Task Automation Tool 🚀

Automate your QA workflows with ease!  
This project helps engineers parse logs, generate reports, and streamline repetitive tasks — all powered by **Node.js + Express** with **Jest** testing.  

---

## ✨ Features
- 📜 **Log Parser** → Extracts errors & warnings from test logs  
- 📊 **Report Generator** → Creates clean HTML reports  
- ⚡ **API Endpoints** → Integrate with your QA pipelines  
- 🧪 **Unit Tests** → Reliable results with Jest
